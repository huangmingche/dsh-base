# Open support chat when configured.

Independent client plugin `client:crisp`, grouped under `dsh-base:crisp` through the official `plugins.bundle.config` slot. This package owns its response validation, fields and actions; browser support supplies only same-origin request lifetime and unchanged official control rendering. Adds no settings section and does not modify DeepSeek Platform account behavior. The server independently authorizes all private reads and writes. Missing configuration and denied access remain explicit. Supports all eight official languages. No purchased template or official source is copied.

The fixed Crisp SDK loads only after an explicit Open support click. No account identity is passed. Missing configuration leaves a disabled button visible; load failures are explicit. Plugin disposal hides chat and removes its owned script.

The plugin registers its own public bundle configuration through the lifetime-scoped `publicPluginConfigurations` compatibility service. The default workbench requires sign-in. The panel and server authorize account and administrator actions. Unloading removes the registration and never exposes private row configuration.
