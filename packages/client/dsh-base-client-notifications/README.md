# 支付通知投递管理

独立客户端插件 `client:notifications`，通过官方 `plugins.bundle.config` 槽位归入 `dsh-base:notifications`。本包独立拥有数据校验、字段与操作契约；浏览器支持库仅提供同源请求生命周期和原样官方控件渲染。不注册设置页，不改动 DeepSeek Platform 账号行为。所有私有数据和写入均由服务端独立授权，配置缺失与权限不足保留明确状态。支持官方八种语言。没有复制商业模板或官方源码。

显示管理员支付通知投递记录与渠道配置。服务商接受不等于送达或已读；发送中或不确定的记录要求先确认已检查上次尝试并接受重复风险。已接受记录不能重试。无任意消息或地址转发。

本插件通过 `publicPluginConfigurations` 兼容服务按生命周期登记自己的公开 bundle 配置入口；匿名用户可查看状态，账号和管理员动作仍由面板与服务端鉴权。卸载插件会注销入口，不开放组件级私有配置。
