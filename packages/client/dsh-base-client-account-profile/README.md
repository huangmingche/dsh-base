# 管理个人资料和密码。

独立客户端插件 `client:account-profile`，通过官方 `plugins.bundle.config` 槽位归入 `dsh-base:account-profile`。本包独立拥有数据校验、字段与操作契约；浏览器支持库仅提供同源请求生命周期和原样官方控件渲染。不注册设置页，不改动 DeepSeek Platform 账号行为。所有私有数据和写入均由服务端独立授权，配置缺失与权限不足保留明确状态。支持官方八种语言。没有复制商业模板或官方源码。

名称、头像和密码分别保存。仅从当前账号的已上传图片选择头像，名称单独保存时保留原头像；不接受任意远程头像地址。密码由 Better Auth 校验并撤销其他会话。

本插件通过 `publicPluginConfigurations` 兼容服务按生命周期登记自己的公开 bundle 配置入口；匿名用户可查看状态，账号和管理员动作仍由面板与服务端鉴权。卸载插件会注销入口，不开放组件级私有配置。
