# 创建和撤销个人 API 密钥。

独立客户端插件 `client:api-keys`，通过官方 `plugins.bundle.config` 槽位归入 `dsh-base:api-keys`。本包独立拥有数据校验、字段与操作契约；浏览器支持库仅提供同源请求生命周期和原样官方控件渲染。不注册设置页，不改动 DeepSeek Platform 账号行为。所有私有数据和写入均由服务端独立授权，配置缺失与权限不足保留明确状态。支持官方八种语言。没有复制商业模板或官方源码。

仅开放 profile:read 权限；网页会话不接受 API 密钥替代登录。创建时显示一次密钥，退出页面或清除结果后不再保留；默认有效30天，可选1–365天。列表支持分页，撤销只操作自己的密钥。

本插件通过 `publicPluginConfigurations` 兼容服务按生命周期登记自己的公开 bundle 配置入口；匿名用户可查看状态，账号和管理员动作仍由面板与服务端鉴权。卸载插件会注销入口，不开放组件级私有配置。
