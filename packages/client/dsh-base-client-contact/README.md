# 向站点团队发送消息。

独立客户端插件 `client:contact`，通过官方 `plugins.bundle.config` 槽位归入 `dsh-base:contact`。本包独立拥有数据校验、字段与操作契约；浏览器支持库仅提供同源请求生命周期和原样官方控件渲染。不注册设置页，不改动 DeepSeek Platform 账号行为。所有私有数据和写入均由服务端独立授权，配置缺失与权限不足保留明确状态。支持官方八种语言。没有复制商业模板或官方源码。

表单需 Turnstile 验证，姓名最多80字符，消息10–4000字符。成功表示服务器接受请求，不宣称收件人已收到或阅读邮件。

本插件通过 `publicPluginConfigurations` 兼容服务按生命周期登记自己的公开 bundle 配置入口；默认工作台要求登录；面板和服务端根据账号权限提供对应操作。卸载插件会注销入口，不开放组件级私有配置。
