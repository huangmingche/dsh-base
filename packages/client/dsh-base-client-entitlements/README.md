# 检查购买获得的功能权限。

独立客户端插件 `client:entitlements`，通过官方 `plugins.bundle.config` 槽位归入 `dsh-base:entitlements`。本包独立拥有数据校验、字段与操作契约；浏览器支持库仅提供同源请求生命周期和原样官方控件渲染。不注册设置页，不改动 DeepSeek Platform 账号行为。所有私有数据和写入均由服务端独立授权，配置缺失与权限不足保留明确状态。支持官方八种语言。没有复制商业模板或官方源码。

只读取服务器配置的功能名单，并按需检查当前账号购买产生的权益；客户端和支付返回地址均不授予权限。

本插件通过 `publicPluginConfigurations` 兼容服务按生命周期登记自己的公开 bundle 配置入口；匿名用户可查看状态，账号和管理员动作仍由面板与服务端鉴权。卸载插件会注销入口，不开放组件级私有配置。

功能可带服务端声明的显示名称 `label`，缺少时显示 ID。部署配置的操作映射在 Host/Think 实际调用前独立检查；此面板的状态和按钮均不是授权依据。
