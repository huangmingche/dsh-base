# @dsh-base/client-locale-url

把官方 locale 运行时与 URL 前缀同步：中文 `/zh-CN`，其余六种语言用各自的裸 id（`/ja`、`/es`、`/fr`、`/de`、`/pt`、`/ru`），英文无前缀。

## 行为

- **启动**：地址带规范前缀时（`/zh-CN/...`、`/ja/...`）选中对应语言；裸地址不强制英文，保留官方运行时保存的语言偏好，并把偏好写回前缀；
- **切换语言**：只改前缀，路径、query、hash 原样保留；
- **`/en/*`**：服务端 301 到裸路径（本插件不自己拼前缀，统一走共享模块）；
- **退役的 `/zh` 路径**：不再有语言语义，按普通 SPA 路由处理，不选中任何语言；
- 前缀规则只来自 `@dsh-base/locale-path`，`check:locale-path` 保证本包不出现第二份字面量。

## 复用决策

官方 locale 插件拥有运行时、词典、设置行与 Host 偏好，但没有地址策略（切语言不会改 URL）。本插件组合官方 locale 服务、只增加前缀同步，不 fork、不替换官方运行时。详见 `package.json` 的 `dshBase.reuse`。
