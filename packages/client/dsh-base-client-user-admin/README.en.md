# Manage site users as an administrator.

Independent client plugin `client:user-admin`, grouped under `dsh-base:user-admin` through the official `plugins.bundle.config` slot. This package owns its response validation, fields and actions; browser support supplies only same-origin request lifetime and unchanged official control rendering. Adds no settings section and does not modify DeepSeek Platform account behavior. The server independently authorizes all private reads and writes. Missing configuration and denied access remain explicit. Supports all eight official languages. No purchased template or official source is copied.

The deployment allowlist determines administrator authority; editing a role label does not grant it. Supports pagination, search, suspension/restoration, role labels and session revocation. Every operation is authorized again by the server.

The plugin registers its own public bundle configuration through the lifetime-scoped `publicPluginConfigurations` compatibility service. The default workbench requires sign-in. The panel and server authorize account and administrator actions. Unloading removes the registration and never exposes private row configuration.
