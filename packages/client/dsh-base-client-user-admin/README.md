# 以管理员身份管理站点用户。

独立客户端插件 `client:user-admin`，通过官方 `plugins.bundle.config` 槽位归入 `dsh-base:user-admin`。本包独立拥有数据校验、字段与操作契约；浏览器支持库仅提供同源请求生命周期和原样官方控件渲染。不注册设置页，不改动 DeepSeek Platform 账号行为。所有私有数据和写入均由服务端独立授权，配置缺失与权限不足保留明确状态。支持官方八种语言。没有复制商业模板或官方源码。

管理员名单由部署配置决定，修改用户角色标签不赋予部署管理员权限。支持分页、搜索、停用/恢复、角色标签和撤销用户会话。所有操作由服务器再次授权。

本插件通过 `publicPluginConfigurations` 兼容服务按生命周期登记自己的公开 bundle 配置入口；匿名用户可查看状态，账号和管理员动作仍由面板与服务端鉴权。卸载插件会注销入口，不开放组件级私有配置。
