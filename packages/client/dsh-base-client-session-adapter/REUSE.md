# Official client Host seam

This package supplies Workers Host contracts to unchanged official plugins. It contains no copied official source. The pinned submodule and `dshBase.reuse` metadata record the reuse decision.

- `remote-mount.ts` invokes the unchanged exported Gateway apply in an isolated Remote scope. It shares the actual Connection and active official Typert registry, owns the sole generation/$events lifecycle, and delegates generated `$mount` with the caller fiber intact. The unchanged official remote-access composition row uses its generated namespace and the authenticated Host owner baseline. No OwnerRemoteAccess implementation or initial local grant remains; non-owner sharing is unavailable. The global original Gateway row stays disabled because this is an internal compatibility dependency while the remaining Host namespaces use the existing facade.
- `settings-remote.ts` sends official argument shapes through official Connection RPC. Host schemas, durable values and revision conflicts are authoritative. Rejections and network failures never become local success.
- `schedule-remote.ts` uses the official Schedule namespace, preserving actions, revisions and failure details. Unchanged official ui-schedule owns its page, sidebar, task details and Session contributions.
- The official HTTP RPC helper is used before `connection` is available. The RPC helper uses an exported `./src/*` entry because the stable entry does not export it; metadata records the reviewed pin.
- The unchanged official permission plugin reads the real catalog and authoritative projection. `/permission` uses the Host command endpoint and its durable execution receipt; failures stay failures and no client-local permission state is invented. The former availability wrapper is inactive inventory.
- Credential requests preserve Host failures. The unused fake sessions service is gone; official api-session-controller owns session lifecycle.
- Plugin inventory maps actual composition inspection to read-only official records in Settings. Disabled originals remain listed without asserting installation or active fibers; runtime rows are never mislabeled as optional bundles.
- Conversation-log feedback is unavailable: official controls are disabled with localized reasons and all writes reject. Settings-sidecar helper tests are unmounted and do not claim official log semantics.
- Directory browsing is the unchanged official plugin over exact Host namespace calls. The removed custom workspace modal and synthetic transcript filesystem no longer substitute for official capabilities.
- Model settings use the official provider-card slot: the Host `modelAccess` endpoint reports platform Gateway/owner-BYOK precedence and the deployment model catalog without secrets; `llm.listProviders` derives availability from that same Host fact. No official Models UI is copied.
- The agent-preset catalog keeps the four pinned official declarations readable and a canonical Cloudflare Think default. The complete marked `@dsh-base/client-agent-preset` fork renders the official controls, including broken official modes as visible/disabled; selection still refuses official ids instead of aliasing them. Generated declarations are build output from the pinned `@deepseek-ai/dsh-web-app` exports.
- Local authentication preserves actual HTTP failures. Billing has no service and uses the official nullable result; a separate official-component availability seam disables required-but-unavailable link fields.
- Analytics collection is intentionally disabled. Empty dynamic-run/job inventories describe no active runs; their mutation methods reject or report no target. Literal client module registration has no HMR lifecycle; the diagnostic static loader's inactive release/retry interface has no product effect.
- Settings/Schedule invalidations follow accepted writes, connection resets and the owner-scoped durable SSE feed. Initial/reconnect baselines and revision deduplication preserve convergence across tabs without carrying private values.

Session/workspace gateways continue to use official unary and mux contracts, with legacy fallback only for explicit endpoint-unavailable errors. Agent token deltas remain on the Agent-bound live carrier.
