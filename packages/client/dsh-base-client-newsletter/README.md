# 通过邮件订阅站点动态。

独立客户端插件 `client:newsletter`，通过官方 `plugins.bundle.config` 槽位归入 `dsh-base:newsletter`。本包独立拥有数据校验、字段与操作契约；浏览器支持库仅提供同源请求生命周期和原样官方控件渲染。不注册设置页，不改动 DeepSeek Platform 账号行为。所有私有数据和写入均由服务端独立授权，配置缺失与权限不足保留明确状态。支持官方八种语言。没有复制商业模板或官方源码。

公开表单要求明确订阅同意和 Turnstile 验证。邮件链接仅打开官方确认对话框，点击确认才提交令牌；取消或成功后清理地址中的令牌。当前账号可取消自己的订阅。管理员恢复区显示确认/退订中的记录，即使公开订阅或邮件发件服务停用也保留恢复通路。原操作至少60秒后，管理员必须先核实供应商原请求已结束并明确勾选，才可“核对供应商并恢复”；操作仅读取供应商状态，不重新发送订阅写入。

恢复读取失败显示不可用；版本冲突不报告成功。普通用户的403不会泄露管理员列表，401清除私有状态。定向检查：`node --test packages/client/dsh-base-client-newsletter/tests/recovery.test.mjs`。

本插件通过 `publicPluginConfigurations` 兼容服务按生命周期登记自己的公开 bundle 配置入口；默认工作台要求登录；面板和服务端根据账号权限提供对应操作。卸载插件会注销入口，不开放组件级私有配置。
