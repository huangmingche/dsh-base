# Dsh-base 公开浏览

复用插件管理页面和官方自动化任务组件，在未登录时查看部署插件目录、浏览任务界面；涉及账号的操作打开登录弹窗。公开目录只有部署声明，不能读取账号配置、会话、工作区或任务。新建任务与手动创建入口都会先请求登录，再由账号界面读取工作区和任务。

客户端插件组成项为 `client:public-navigation`。用户批准的匿名行为差异与官方导出来源记录在 package.json 中。

匿名详情仍显示配置入口；未登记的私有配置只显示官方登录按钮，不挂载其中的账号或管理员表单。真实账号的插件选择、配置和任务始终需要原有授权。

默认拒绝匿名挂载所有配置。插件可通过导出的 `publicPluginConfigurations.registerBundle(key)` 服务显式登记自己已包含操作鉴权的公开 bundle 配置。服务按生命周期与引用计数注销，变动立即刷新视图；未登记 bundle、global 私有配置与所有 `plugins.row.config` 仍显示登录入口。
