# 插件数量

在插件页面的分类标题旁显示数量。内置插件配置统计配置入口，实验性插件和“更多”统计该列表实际展示的插件；已安装插件同时显示插件包数和包含的组件数。

## 官方复用

已检查固定版本 `dsh-v0.2.2-rc.1`（`66491b05e3f05ad35bcdd4f6cd7ed26041d9e3db`）中的 `@deepseek-ai/dsh-client-ui-plugin-manager`。官方详情页已有组件总数和状态统计，但分类标题没有数量，也没有对应的标题插槽；官方的详情统计实现不适用于分类。

现有完整标记 fork `@dsh-base/client-plugin-manager` 只增加可选的 `dsh-base.plugins.group.summary` 行内插槽，将同一次渲染的分类数据和官方 `sectionCount` 样式类传入。本插件通过已导出的 `./group-summary` 类型契约贡献计数，不复制页面或官方筛选规则。新增计数是用户明确要求的界面差异，已记录在包元数据中。官方详情页的组件统计保持原样。

## 数据和行为

- 只读取页面已经选出的配置入口、插件包和组件 ID，不增加网络请求、后台任务或 DOM 扫描。
- 插件包按身份去重，组件按所属插件包和组件 ID 去重。关闭、不可用和只读条目仍计入对应可见分类。
- “更多”包含主列表中的实验性插件；不会跨分类相加，避免重复统计。
- 未完成加载、首次加载失败或不可用时不显示虚假的 `0`；成功加载后随页面快照更新。计数描述当前显示的列表，不声称存在新的运行状态。
- 不改变安装、启停、权限或运行状态。插槽或插件卸载后，计数随官方注册生命周期移除。
- 使用官方辅助文字的字号和颜色；独立样式类沿用官方详情统计的 10px 逻辑间距、基线对齐与普通字重。空间不足时整段统计换行，避免标题与数量挤在一起；没有计数时不会留下空隙。
- 提供中、英、日、西、法、德、俄、葡八种语言及相应无障碍说明。

插件由 `dsh.client` 和 `dshBase.client` 元数据组合，ID 为 `client:plugin-counts`；应用入口不包含功能代码。它自身也纳入完整自有插件清单。
