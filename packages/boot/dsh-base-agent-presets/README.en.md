# @dsh-base/agent-presets

Canonical Agent preset identities for this deployment: `dsh-base-think` (the Cloudflare Think composition actually running) and the official `standard`/`ptc`/`minimal`/`cordis` ids (which keep their official meaning and are never aliased to Think).

- Client, Worker, Think and docs share the same constants;
- Official ids never equal the fixed runtime; creating a Session with an official id is refused;
- Historical Session projections use canonical `dsh-base-think`;
- The official declaration copy is generated by the client plugin from the pinned `@deepseek-ai/dsh-web-app/presets/*.patch.yml` exports; this package copies no official declaration.

## Availability copy

`./availability` exports localized copy for the fixed `dsh-base-think` composition and the four platform-unavailable official modes (neutral badge/reason, read/select and Creator reasons). It is packed data for the marked `@dsh-base/client-agent-preset` fork and the session adapter; it registers no slots and renders no UI.
