# DeepSeek Harness Base

[简体中文](README.md) | English

DeepSeek Harness Base (`dsh-base`) is an application development template built on DeepSeek Harness. The project pins an official DeepSeek Harness release through a Git submodule and updates the corresponding submodule to match new upstream releases.

DeepSeek Harness Base follows the “Everything is a Plugin” principle. Developers can reuse official dsh plugins and write their own dsh plugins as needed. They can then combine their chosen dsh plugins into a standalone application and deploy it to Cloudflare Workers.
