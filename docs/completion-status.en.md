# Release scope and verification

This version composes custom Client, Worker and Think plugins. The application profile and pack metadata identify the selected entries. Provider readiness and feature switches depend on the deployment. Run `pnpm check`, `pnpm build:all` and the relevant browser acceptance suites before release. Each result belongs to the actual run and build it covers.
