# 站点收录与转化统计

简体中文 | [English](seo-plugins.en.md)

发布、配置和下游扩展规范只维护在 [AGENTS.md](../AGENTS.md#公开内容收录与商业化)。本文说明实际能力和边界，不代表已经部署或接通外部服务。

| 能力 | 当前实现 | 边界 |
| --- | --- | --- |
| 页面 SEO | 标题、描述、canonical、hreflang、OG、Twitter、站点与组织 JSON-LD | hreflang 只列实际译文；SEO 设置不能创建页面 |
| sitemap.xml | 列出生产站点允许收录的已发布页面 | Staging 提供空 sitemap |
| robots.txt | 私有路径规则；仅索引开启时声明 sitemap | 登录页允许抓取以识别 noindex；权限仍由认证服务校验 |
| manifest 与图标 | 独立应用清单；透明黑白鲸鱼 favicon 与安装图标 | 不替代内容发布或身份认证 |
| llms.txt | 站点简介、已发布可索引页面与真实语言版本 | 不暴露私有对话，不生成不存在的全文链接；不是搜索排名保证 |
| 套餐与购买 | 工作台的 Waffo Pancake 面板展示配置的价格和权益，支持登录后恢复结账 | 结账需要已配置的支付服务 |
| 权益校验 | 显式配置的付费操作由服务端校验；平台 AI 每次调用前复查 | 缺少映射保留免费行为；自带 API Key 不改；退款与到期不能靠旧客户端状态绕过 |
| 统计 | 原有公开 page_view，加注册、首次完成、结账和购买的第一方日汇总；可选 Google 转化 | 默认关闭；Google 转化需要明确同意；不提供可靠独立访客或跨设备归因 |

底座登记了工作台首页的八种语言版本。鉴权、SEO、sitemap、llms 和页面统计共用这份目录。业务项目可以通过自己的 Worker 插件登记页面。未知地址和缺少译文的地址返回 HTTP 404。

全局设置仍保存一份带 revision 的 D1 文档。管理员身份、同源写入和版本冲突校验保持生效；页面覆盖下拉项来自当前目录。停用内容提供方会撤下其导航与发现链接，旧 SEO 覆盖不能重新发布页面。

转化由真实成功事件触发：注册由认证钩子确认，激活在会话持久化完成后确认，购买由已验签支付通知和实际付款金额确认。D1 批次保存去重凭据与日汇总，支付统计故障不撤销已完成交易或权益。Google 不接收账号标识、会话内容、访客 IP、Referer 或任意查询参数；活动标签必须来自配置白名单。真实 GA 报表、Waffo Pancake 商户交易和搜索引擎收录仍须运营者配置后单独验收，HTTP 成功不等于报表入库。

启用第一方转化时增加按事件计费的 D1 写入，Google 模式还会增加受控外部请求。完整计数和最近已部署版本见[实现与验收状态](completion-status.md)。
