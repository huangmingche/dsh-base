# 发布前审查

本次审查以 `AGENTS.md` 为验收规则：产品是官方 DSH 插件的组合，Workers/Think 负责有明确边界的 Host 适配；声明、实际能力和界面反馈必须一致。记录日期：2026-11-10。本页区分本地门禁、已部署版本和真实云端验收，不将未执行的检查视为通过。

## 第一性原理结论

仓库成立的条件不是“页面看起来像 DSH”，而是四个可验证事实：官方依赖有固定且干净的来源；所有产品能力都通过插件组合提供；用户操作落实为可恢复的持久状态；平台不支持的官方能力仍可见并明确拒绝。模板还必须在新账号、新仓库中独立配置，不能继承维护者资源或共享凭据。

因此，静态清单的 100% 覆盖只说明官方条目没有遗漏，不证明整个产品 100% 保真，更不证明 Think 与官方执行引擎等价。当前可执行的验收分别检查元数据、真实 fiber、Host 故障恢复、浏览器交互，以及指定官方组件的文本/布局/截图对照。

## 已处理的问题

- **官方来源与组合**：release tag、commit、tree 与干净工作区校验；exports 审查、源码入口升级审查、运行平面边界及检查器负例；禁用库存不加载代码，替换关系可检查。应用只保留入口、部署和组合。
- **事件与历史一致性**：用真实官方会话组装器复现并修正审批续跑的 Context 开始/更新顺序、同 ID 工具结果丢失和旧实时帧重播。一次用户请求保持一个回合，工具与续答属于内部步骤；等待审批不能提前显示“已完成”，缺少结果记录的旧历史不能推测成功。用真实 Sessions + SQLite 修复指令更新形成错误历史分支的问题，保留用户/助手记录并覆盖故障重试。右侧栏通过有来源记录的最小 fork 区分正常引用释放与真实加载失败。
- **协议完整性**：重复创建采用原子幂等和官方空会话复用规则，保留模型/标题/历史/队列，不支持的位置明确报错。POST 实时状态统一返回明确的成功/失败信封，空闲状态使用 `live: null`，防止官方订阅因空对象退出；GET 实时端点保留其原始协议。命令目录不再把无法执行的自有委派技能当作可用功能。
- **持久化与恢复**：保持 `owner:<userId>:default-v49`；迁移失败不伪装空数据，完成标记原子提交；请求幂等、取消竞态、执行回执重放与工作区归档停止均有故障测试。BYOK 读取/解密失败不回退平台密钥。
- **官方 UI 与能力**：复用官方 Schedule、目录浏览器、插件管理器、账户及设置；修复重复设置导航、禁用选项键盘绕过、假余额/假反馈、终端和权限假行为。支持八种官方语言的偏好保持；中文会话/工作区深链接保持路径并可恢复。
- **登录主题**：线上截图复核发现深色背景与浅色前景变量混用；修复为官方 ThemePresenter 和实际 token，补上中英文、三种注册策略、明暗及系统热切换的真实插件验收。
- **品牌**：通过官方 slots 和导出标志让侧栏显示代码名 `dsh-base`（产品显示名 `DeepSeek Harness Base` 用于 README/文档），移除侧栏版本，保留设置版本。此差异由用户明确批准。额外 About/支持/环境菜单默认不启用，避免未经批准的官方 UI 扩展。
- **文件与预览**：官方上传客户端及 HTTP 处理器，R2 文件与会话凭据、原子消费、重试与分叉恢复；Think 按会话读取已批准文件。恢复真实 PDF.js/Excel Worker、同版本字体与数据资源、FortuneSheet CSS；坏文件明确失败。
- **能力真实性**：早期修复先拒绝无后端的 Effort；本轮已补真实提供商参数和持久执行配置。没有模型服务时目录显示不可用；图片处理缺少真实解码/归一化服务，官方零图片限制与服务端明确拒绝共同生效。
- **执行结果与来源**：工具错误/拒绝使用官方错误标记；工具拒绝与请求取消分别处理。模型来源从实际执行模型持久化，不再把所有回答标成 Flash；缺少来源证据的旧历史保留未知，不拿当前选择反推过去。
- **步骤、模型与统计**：同一 SDK 消息内的多个步骤拥有稳定且唯一的官方消息标识；本轮分叉进一步精确到所选事件，并由官方算法关闭开放工具/步骤。模型投影使用官方 `{lastUsed, next}`，刷新后保持持久化的选择；`lastUsed` 使用执行时已冻结的请求选择；提供商响应型号单独记录，缺失证据时保留未知。统计按真实 SDK 步骤计数，审批续跑不新增用户回合，重放标记与累计值原子提交。
- **认证与模板安全**：公开注册/平台付费模型默认关闭；管理员令牌创建账号，历史公开共享验收账号及旧 cookie 停用但不删除数据；全局插件写入同时校验账号与管理员令牌；阻止跨来源修改和 WebSocket 升级。
- **模板可移植性**：移除默认私人 Worker/D1/R2/Gateway 资源；初始化脚本验证输入且拒绝覆盖既有身份；密钥和部署配置忽略，冻结依赖、版本约束、CI、双语说明与上游/依赖许可随产物发布。远程验收必须明确指定目标与独立账号。
- **依赖公告**：Better Auth 升至 `1.7.18`，对 `guarded-fetch` 的 Undici、公式解析的 KaTeX、表格依赖的 UUID 使用限定消费者的修复版本；实际 CommonJS UUID 与数学渲染兼容检查通过，完整开发/运行依赖扫描当前均为零已知公告。原始扫描和复查保存在忽略目录，不将扫描结果解释为无任何安全风险。参考 [Better Auth 公告](https://github.com/better-auth/better-auth/security/advisories/GHSA-965c-763c-88jm)、[UUID 公告](https://github.com/uuidjs/uuid/security/advisories/GHSA-w5hq-g745-h8pq)、[KaTeX 公告](https://github.com/KaTeX/KaTeX/security/advisories/GHSA-238p-pmpm-9mq7)。
- **依赖运行时契约**：浏览器 React、ReactDOM 与类型版本对齐锁定的官方依赖；Cloudflare SDK 的 React 19 peer 单独隔离于构建依赖包，禁止其 React 入口进入浏览器。严格 peer 安装与负例检查阻止通过忽略规则伪造兼容性。
- **模板构建路径**：统一根工作区与单锁文件，保留全部 707 项依赖解析；消除 Cloudflare CLI 扫描应用目录外工作区时无法抵达停止目录的循环。根目录一次冻结安装即可，CI、检查器及中英文说明使用同一拓扑。
- **类型与错误传播**：分别严格检查自有 Client、Worker/Think 与应用/Vite 入口；官方声明从锁定源码/真实 Remote 生成器输出到被忽略目录。修复缺失 SDK API、声明前引用、未释放上下文、HTTP 错误/空信封被当成功等问题。依赖声明生成不代表对上游全部源码做语义检查。

## 剩余差异的准确分类

完整清单见 [官方差异分类](official-differences.md)。原生 PTY/子进程、用户本机目录和持久 POSIX 文件系统是当前纯 Worker isolate 的真实边界。图片归一化、完整子代理、多预设/child-root、动态插件/HMR、通用任务与完整原生执行语义属于未完成集成，不再称为 Workers 不可能实现。官方账户/账单和日志反馈还需要外部服务契约。

本轮补接真实模型/Effort、会话权限、提交后的推送与跨标签页刷新、真实 SDK 工具/步骤证据、D1 认证限流，以及官方 Cron/夏令时处理。精确分叉直接复用官方 buildForkSeed，持久前缀和保守关闭结果，不保留切点后的工具结果，并保留工作区。缺失的旧历史证据不能重建；没有原执行配置的旧审批不借用当前设置续跑。

投影变化使用事务内持久版本，聊天事件仍使用自己的连续游标。此 Host 适配解决同聊天游标更新丢失及浏览器时间戳压住真实变更的问题，但两个序列尚未合并为官方单一事件日志。历史切点的权限策略仍继承源会话当前持久策略，累计用量缺少切点证据时不复制。不能将这些适配声称为完整原生事件溯源等价。

本地模拟器显式使用其支持的 `2026-10-30`，云端部署兼容日期保持 `2026-11-06`。真实云端模型、连接和重载行为必须单独验证，不能由本地替代。

Cloudflare 的活动 Durable Object 可能在部署后短暂保留旧代码。线上模型验收先核对 Host 自身的 `WORKER_VERSION.id`，精确匹配本次部署后才提交模型输入；只对旧版本/旧字段做有界等待，不吞掉认证、业务或协议错误，也不通过变更存储身份绕过更新。
